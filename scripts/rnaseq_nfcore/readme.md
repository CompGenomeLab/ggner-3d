The scripts in this folder are used to run the nf-core/rnaseq pipeline and to generate signal tracks from the resulting alignment files.

1. **run_nf.sh**: Runs the nf-core/rnaseq pipeline for the RNA-seq samples.
2. **bigwig.sh**: Generates CPM-normalized bigWig files from merged, duplicate-marked, and sorted BAM files for each RNA-seq condition for downstream analysis in the manuscript.
