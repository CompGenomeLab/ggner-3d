The scripts in this folder are used to run the nf-core/chipseq pipeline v2.1.0 and to generate signal tracks from the resulting alignment files.

1. **run_nf.sh**: Runs the nf-core/chipseq pipeline for the XPC ChIP-seq samples.
2. **rpgc.sh**: Generates RPGC-normalized bigWig files from the pipeline alignment files.
