The scripts in this folder is used to run the nf-core/chipseq pipeline v2.1.0, and resulted alignment files are used to generate the signal tracks.

1. **run_nf.sh**: This script is used to run the nf-core/chipseq pipeline.
2. **run_bw.sh**: This script is used to generate the signal tracks from the alignment files produced by the nf-core/chipseq pipeline e.g the RPGC normalized bigwig files that is used for downstream analysis in the manuscript.
